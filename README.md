# Student Management

## Project Description

Student Management is a simple web-based application developed for managing basic student records using HTML, CSS and JavaScript.

## Features

- Add Student
- Display Student Details
- Search Student by ID
- Delete Student Record

## Technologies Used

- HTML
- CSS
- JavaScript
- Git
- GitHub

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Git Workflow

This project follows a feature-based Git workflow.

The main branches are:

- `main`
- `develop`

Feature development is carried out using:

- `feature/add-student`
- `feature/search-student`

Completed feature branches are merged into `develop`. After integration and completion of the project, `develop` is merged into `main`.
