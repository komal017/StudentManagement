# Student Management System

## Introduction

Student Management System is a simple web-based application developed to manage student records.

## Features

- Add Student
- Display Student Details
- Search Student by ID
- Delete Student Record

## Technologies Used

- HTML
- CSS
- JavaScript
- Git
- GitHub

## Git Workflow

The project follows a feature-based Git workflow using:

- main
- develop
- feature/add-student
- feature/search-student

Feature branches are merged into the develop branch. After completing development, the develop branch is merged into the main branch.

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
